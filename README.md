> [!WARNING]
> **Work in progress. Do not use this package yet.**
>
> There is no release here and no `Package.swift`, so nothing will resolve. The manifest and the
> pre-built XCFrameworks arrive with njia's first release.

This repository will be the Swift Package Manager distribution for **njia**, the flow navigation
engine behind the Smile ID SDKs. It will host the generated `Package.swift` manifest and the
pre-built XCFramework binaries (`Njia`, `NjiaUI` and `NjiaTesting`), published from
[smileidentity/njia](https://github.com/smileidentity/njia) the same way
[kamera-spm](https://github.com/smileidentity/kamera-spm) is published from kamera.
